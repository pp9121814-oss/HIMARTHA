HIMARTHA — Aipan Art Clocks website

FILES
- index.html: responsive website with HTML, CSS and JavaScript
- assets/: artwork crops made from the reference image you supplied

BEFORE PUBLISHING
1. Open index.html in a browser to preview.
2. In index.html, find const WHATSAPP_NUMBER="91XXXXXXXXXX" and replace it with your WhatsApp number in international format, digits only. Example: 919876543210
3. Edit demo prices/product details if needed.
4. Upload index.html and the complete assets folder to the root of your GitHub repository.
5. Enable GitHub Pages in repository Settings > Pages.

Working features: responsive layout, water-drop overlays, product filters, search, wishlist, cart, cart total, mobile menu and WhatsApp order message. WhatsApp checkout remains in demo mode until you add your number.
