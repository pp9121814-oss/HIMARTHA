HIMARTHA — FULL STORE PACKAGE
================================

WHAT'S INCLUDED
- index.html       Premium customer-facing store
- admin.html       Secure owner login + product management dashboard
- store.js         Supabase live product loading, cart, wishlist, filters, WhatsApp checkout
- admin.js         Product CRUD + image upload to Supabase Storage
- config.js        Your public Supabase project URL/key and WhatsApp number
- supabase-schema.sql   Database tables, RLS policies, storage bucket and demo products
- assets/          Reference-matched Aipan clock imagery

SETUP (one time)
1. Create a Supabase project.
2. In Supabase, open SQL Editor, paste/run supabase-schema.sql.
3. In Authentication > Users, create the owner login with email/password. Disable public sign-ups in Authentication settings if enabled.
4. Copy the owner's user UUID from Authentication > Users.
5. In SQL Editor, run this query with the real UUID:
   insert into public.admin_users (user_id) values ('PASTE-OWNER-UUID-HERE');
6. Open config.js and set:
   SUPABASE_URL = "https://YOUR_PROJECT_ID.supabase.co"
   SUPABASE_PUBLISHABLE_KEY = "sb_publishable_..." (or your project's legacy anon public key)
   WHATSAPP_NUMBER = "91XXXXXXXXXX" (digits only; India example format)
   Never use a secret/service_role key in the website.
7. Upload all files/folders in this package to the ROOT of your GitHub Pages repository. Keep the assets folder.
8. Visit /admin.html, sign in with the owner account, and add a product. Published products appear in the customer store.

SECURITY
- Frontend uses only the public/publishable key.
- RLS policies limit insert/update/delete to UUIDs in public.admin_users.
- The admin panel does not provide public sign-up.
- Keep the owner password private. Do not add a service_role key to any frontend file.

WHATSAPP
- Checkout composes the selected products, quantities and total in a WhatsApp message.
- It does not process payment or create an order record in a backend by itself.
- Configure the real WhatsApp business number in config.js.
- Demo prices are examples. Replace them with your real product pricing.

NOTES
- If the SQL demo product rows run, their example image_url values are relative paths. To use demo rows immediately, upload the five image files to a public bucket or replace their image_url values with absolute public URLs. The store has local fallback cards when Supabase isn't configured.
- For live products, upload photos from admin.html; the resulting public Supabase Storage URL is saved in products.
- Test RLS and Storage policies in a test project before handling real customer data.
